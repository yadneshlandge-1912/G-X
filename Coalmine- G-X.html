MVP v1.0 — Underground Mine Safety

CoalMine LoRa+AI Monitoring Platform

A miner-safety system built for the constraint that actually matters: most underground coal mines have no mobile signal at all. Everything here runs on LoRa radio and local processing — no SIM, no internet, no cloud dependency.

70%+ of underground coal mines operate in zero-coverage zones. This system is designed to work fully offline, end to end, from sensor node to dashboard.

01

Architecture

Sensor readings travel from miner-worn nodes to a surface gateway over LoRa, then through a two-agent backend pipeline before reaching the live dashboard.

The WebSocket layer pushes live state straight to the React dashboard, so every alert, reading, and location update appears on screen within the same second it's decoded from the gateway.

Quick start — demo, no hardware

The backend simulates all five nodes with realistic drift and occasional alerts whenever no serial port is present, so the full system can be demoed without any physical hardware.

# Backend (simulation mode auto-activates without a serial port) cd backend npm install npm start # Dashboard (new terminal) cd dashboard npm install npm run dev # Open http://localhost:5173 # All 5 nodes simulate live data with realistic drift + occasional alerts
05

Key design decisions

Every major choice traces back to one of the real constraints of an underground mine deployment.

Zero mobile coverage underground
LoRa 915MHz, spreading factor 12 — 500m+ range through rock and bends
No internet at the pit head
Offline-first SQLite database, with a sync queue for later cloud upload
Noisy RSSI readings
Kalman filter in Agent 1, paired with a median filter in Agent 2
No GPS underground
RSSI path-loss model plus a particle filter over the tunnel graph
Sensor failures
Flatline detection and spike detection built into Agent 1
Miner entrapment
30s / 120s heartbeat watchdog, plus an SOS button on every node
DGMS compliance
Thresholds matched to the Coal Mines Regulations 2017, Regulation 167
Power cuts
UPS on the gateway, 72-hour battery reserve on each miner node
06

Scalability path

The MVP is a single-gateway, single-section deployment. Here's how it extends.

More mine sections
Deploy additional gateways, each carrying its own section ID.
True trilateration
Multiple gateways let Agent 2 move from single-anchor to three-anchor positioning.
Cloud sync
Flush the sync_queue to any REST endpoint — BSNL, AWS, or GovCloud.
Multilingual OLED
Swap English labels for Hindi transliteration directly in the firmware.
Blockchain audit trail
Hash each readings row and publish it to a permissioned chain.
